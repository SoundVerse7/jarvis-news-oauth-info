# JARVIS News Autopilot — Public OAuth Information Website

Public, informational website for a **private desktop application** serving **Public Mind Report - World News**. The actual JARVIS application and its code are in a separate private repository. **Never upload OAuth JSON files, tokens, passwords, databases, footage, or internal logs here.**

## Site pages
- `index.html` — home page and Google OAuth access summary
- `privacy.html` — privacy policy and YouTube API data practices
- `terms.html` — terms of use
- `styles.css` — responsive black/red design
- `assets/pm-emblem.svg` — public-only vector logo
- `.nojekyll` — serve this site without Jekyll

## Enable free GitHub Pages
On this repository, visit **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, and **Save**.

Expected URLs *after publication*:
- Home: https://soundverse7.github.io/jarvis-news-oauth-info/
- Privacy: https://soundverse7.github.io/jarvis-news-oauth-info/privacy.html
- Terms: https://soundverse7.github.io/jarvis-news-oauth-info/terms.html

This is a public GitHub Pages site without external scripts, logins or payments. It does **not** automatically verify domain ownership with Google, change the OAuth publishing status, remove sensitive-scope verification, increase quota, or lift YouTube's audit-related restriction on public uploads. Google may require proof of control of the app's homepage domain and further compliance checks.

For support, use this repository's issue tracker, without posting private OAuth material.
