Privacy policy

How the public news site and the separately operated JARVIS Windows app handle data.

1. Who operates this site and app?

Public Mind Report - World News operates a public, informational news website and a separate, privately operated Windows application called JARVIS News Autopilot. This is not a public OAuth sign-in service. For inquiries, use the public information repository. Do not include credentials or personal financial details in GitHub issues.

2. News website visitors

The site does not require registration and currently sets no first-party analytics cookies or behavioral tracking scripts. This static site is served through GitHub Pages. The browser also requests public headline data from GitHub's public Contents API and may fall back to a locally hosted JSON file. GitHub may receive customary network data such as IP addresses and browser request details under GitHub's privacy statement. Clicking YouTube links or links to other news sources takes you to those services under their own privacy terms.

3. Automated news content

The news desk downloads publicly distributed RSS feed data on GitHub-hosted automation, extracting source names, headlines, dates and public links. Those news items do not include Google account data. News data is stored in the publicly visible website repository and updated on an automated schedule. It contains no JARVIS authorization tokens.

4. Data requested from Google by JARVIS

When the channel owner authorizes the Windows application through Google's official OAuth flow, the application uses the YouTube Data API to identify the authorized channel, read its details and video metadata, and perform owner-authorized video-management actions such as uploads. The YouTube Analytics API is used to read channel statistics, such as views, subscribers and watch metrics, to assess channel performance. Requested Google permissions include YouTube account-management access and read-only YouTube Analytics access. The application does not ask for the owner's Google password.

5. Why JARVIS uses that data

Account data is used to ensure the app is connected only to the owner's selected YouTube channel, prevent duplicate or unauthorized uploads, monitor video publication states, and understand performance. It is not sold, rented, or shared with advertisers. Public website readers do not need to authorize any Google access.

6. Where OAuth credentials are stored

The Windows application stores its OAuth refresh token locally on the owner's PC, encrypted with Windows Data Protection API (DPAPI). Its local records may include production jobs, source references, analytics and audit logs. The public GitHub Pages website does not hold or publish OAuth secrets, owner tokens, private video files or personal YouTube Analytics reports. The owner is responsible for controlling access to their own PC and private project.

7. Data sharing and retention

JARVIS communicates with Google's APIs only for owner-authorized features. Local operational data is retained as needed to support app functions and audit history; it is not automatically erased just because the Google account is disconnected. The site's public headline snapshot may remain in GitHub commit history after subsequent refreshes. Third-party services are governed by their own privacy policies.

8. Revoking access and deleting local data

The account owner can revoke JARVIS authorization through Google Account connections. In the app's Windows project directory, the owner may run python jarvis.py youtube disconnect to disconnect. After revocation, locally stored project records or logs may require separate manual deletion. For requests about the publicly hosted site, open a GitHub issue without including secrets.

9. Public YouTube channel previews

To display recent videos from the public Public Mind Report and World News channels, the website shows public video titles and links retrieved through YouTube's public feeds. Video thumbnails load from YouTube's image service, which may receive normal browser request information. Clicking a video or Subscribe opens YouTube under Google's policies. No personal account details are collected by this website.

Google API Services User Data Policy: JARVIS's access to data received from Google APIs is governed by the Google API Services User Data Policy, including its applicable Limited Use requirements. Google also publishes its Privacy Policy.
